## Sprite, Latar, dan Prop Visual
- Seluruh sprite karakter, latar, prop, UI, dan tekstur grain dibuat prosedural oleh script lokal (`scripts/sprite_builder/`, `scripts/make-grain.py`) — karya orisinal proyek ini (CC0 / bebas digunakan untuk tugas praktikum).

## SFX (`public/sfx/*.wav`)
- Seluruh SFX dihasilkan secara prosedural oleh `scripts/synth-sfx.mjs` (sintesis DSP lokal, tanpa sampel suara manusia/vokal) — bebas royalti / orisinal proyek (detail per file di `public/sfx/sfx-manifest.json`).

## BGM (`public/music/*.wav`)
- Seluruh BGM dihasilkan secara prosedural oleh `scripts/synth-bgm.mjs` (chiptune/ambient instrumental lokal, tanpa vokal) — bebas royalti / orisinal proyek.
